# 🎮 Lost — Discord Games Bot (Node.js)

بوت ألعاب ديسكورد بواجهات Modern (أزرار، Select Menus، Modals) — `Lost © 2026`
مكتوب بـ **discord.js v14** (تحويل كامل من نسخة بايثون).

## التشغيل
```bash
npm install
cp .env.example .env        # ويندوز: copy .env.example .env  ثم ضع DISCORD_TOKEN داخل الملف
npm start
```
المتطلبات: **Node.js 20 أو أحدث**.

> ملف قاعدة البيانات القديم `data/lost.db` (بتاع بايثون) يشتغل زي ما هو — انسخه داخل مجلد `data/`.

## إعداد البوت في Developer Portal
1. https://discord.com/developers/applications → New Application → Bot → انسخ التوكن.
2. فعّل **Privileged Gateway Intents**: `SERVER MEMBERS INTENT` + `MESSAGE CONTENT INTENT`.
3. OAuth2 → URL Generator: scopes `bot` + `applications.commands`،
   صلاحيات: Send Messages, Embed Links, Read Message History, Manage Messages (اختياري).
4. للتجربة السريعة ضع `DEV_GUILD_ID` في `.env` (مزامنة فورية للأوامر).

## 🎛️ الداشبورد (جوه ديسكورد — مش موقع)
اكتب `dashboard` (أو `/dashboard` أو `داشبورد`) — للإداريين فقط:

1. يظهر **بار** فيه كل الأقسام: 🛡️ الإدارة · 🎮 فردي · 👥 ثنائي · 🌐 جماعي · 🛠️ أدوات (+ صفحات الإعدادات: العامة / الألعاب / الاقتصاد).
2. اختار قسم → يظهر **بار ثاني** فيه كل أوامر القسم.
3. اختار أمر → واجهة التعديل:
   - ✏️ **تعديل**: الاسم بالإنجليزي، الاسم بالعربي (تقدر تحط أكتر من اسم مفصولين بفاصلة)، والوصف بالعربي والإنجليزي.
   - 🔓 **بدون بادئة**: تشغيل/إيقاف تشغيل الأمر من غير بريفكس.
   - ♻️ **استرجاع الافتراضي** · ⬅️ **رجوع**.

التعديلات **لكل سيرفر** وتتحفظ في قاعدة البيانات وتشتغل فوراً.

## الأوامر تشتغل بـ 3 طرق
| الطريقة | مثال |
|---|---|
| Slash | `/xo @user` |
| Prefix (افتراضي `!`) | `!xo @user` |
| **بدون بادئة** (افتراضياً مفعّلة) | `xo @user` · `اكس_او @user` · `نقاط` · `توب` |

أسماء عربي افتراضية: `داشبورد` `مساعدة` `اعدادات` `لغة` `بادئة` `تصفير` `رياضيات` `كتابة` `اعلام` `اكس_او` `حجر` `كونكت4` `عجلة` `سباق` `نقاط` `توب` `متجر` `عن_البوت`.

**ملاحظات:**
- الكلام العادي في الشات مش بيتفسّر أمر: الأمر بدون بادئة لازم يكون الكلمة الأولى وبدون كلام زيادة (مثلاً "help me please" مش أمر).
- أسماء أوامر الـ Slash ثابتة بالإنجليزي (ديسكورد مفيهوش لغة عربية للأوامر)؛ التعديل بيخص الأسماء النصية (بادئة / بدون بادئة) والأوصاف في `/help` والداشبورد.
- لو أمر بيتعارض اسمه مع أمر تاني، الداشبورد يرفضه ويقولك.

## الهيكل
- `index.js` / `config.js` — التشغيل والإعدادات
- `core/` — البوت، `commandManager.js` (الأسماء والتعديلات)، `ctx.js` (نفس الكود لـ Slash والنص)، Embeds، Views، ترجمة AR/EN
- `commands/` — الأوامر مقسمة حسب الفئة (`dashboard.js` = الداشبورد)
- `games/` — `base.js`، `lobby.js` (غرف حتى 99)، `xo.js`، `roulette.js`
- `database/` — SQLite عبر better-sqlite3 + `schema.sql`
- `assets/help.png` — صورة قائمة help

## إضافة أمر / لعبة جديدة
1. ضيف تعريف الأمر في ملف داخل `commands/` (شوف أي أمر موجود كمثال: `key`, `slash`, `names.en/ar`, `desc.en/ar`, `usage`, `options`, `run(ctx, args)`).
2. سجّله في قسمه داخل `SECTIONS` في `core/utils.js` — يظهر تلقائياً في `/help` وفي الداشبورد.
3. لو لعبة: ضيفها في `GAMES` و `GAME_NAMES` واستخدم `gameEnabled` و `finish()` لمنح النقاط.
